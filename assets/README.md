# App icon

`app-icon.png` is the transparent master artwork, generated with the built-in
imagegen tool. The app embeds it for the running Dock icon; the macOS packaging
script creates the Finder/Dock `.icns` sizes from the same source.

Generation prompt:

> Use case: logo-brand. Asset: a production macOS application icon for Better Slack, a minimal native chat client inspired by old IRC and Swedish industrial design. Create ONE centered square icon on a genuinely transparent background at 1024x1024. A warm off-white softly rounded macOS squircle tile, occupying about 86% of the canvas, with very subtle porcelain depth and a restrained soft shadow. Center a bold, geometrically precise dark charcoal hash/channel symbol (#), with slightly softened ends and generous breathing room. A single small muted Scandinavian blue chat-cursor bar is integrated as a quiet accent in the lower right of the mark. Strong silhouette, clear at Dock sizes, extremely simple, balanced, calm, premium native Mac utility. Front view, no perspective. No words, no letters, no tiny decorative details, no Slack multicolor pinwheel, no surrounding scene, no glossy gradient, no mockup, only the finished standalone app icon. Preserve transparent space outside the squircle.
